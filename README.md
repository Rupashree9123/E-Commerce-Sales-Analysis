# E-Commerce-Sales-Analysis
Python, MS Excel

Project Overview

This project analyzes e-commerce sales data using Python to identify revenue trends, evaluate category performance, monitor order statuses, and generate actionable business insights.

Business Objectives

* Analyze monthly revenue trends and sales performance.
* Identify top-performing product categories.
* Calculate key business KPIs.
* Evaluate return and cancellation rates.
* Provide data-driven business recommendations.

Tools & Technologies

* Python
* Pandas & NumPy – Data processing and analysis
* Matplotlib & Seaborn – Data visualization
* Jupyter Notebook – Development environment

Dataset

The dataset contains **1,000 orders** from **200 unique customers**, with information about order dates, products, categories, quantities, prices, discounts, locations, and order statuses.

Data Preparation

* Checked for missing values and duplicate OrderIDs.
* Converted the order date column into datetime format.
* Calculated revenue after applying discounts.
* Validated order quantities, discount values, and order statuses.

Key Performance Indicators (KPIs)

* **Total Revenue:** ₹24.04M
* **Total Orders:** 1,000
* **Total Customers:** 200
* **Average Order Value (AOV):** ₹24,041.75
* **Return Rate:** 7.40%
* **Cancellation Rate:** 4.60%
* **Average Discount:** 8.57%

Key Insights

* **Category Performance:** Electronics generated approximately ₹18.38M, contributing around 76% of total revenue.
* **Monthly Trends:** April recorded the highest monthly revenue of ₹3.62M, while March recorded the lowest at ₹1.54M.
* **Order Status:** 88% of orders were delivered, 7.4% were returned, and 4.6% were cancelled.

Business Recommendations

* Prioritize inventory planning and product availability for Electronics.
* Investigate monthly revenue fluctuations to identify factors affecting sales.
* Analyze returned orders to identify potential product or fulfillment issues.
* Investigate cancellation patterns to improve order completion.
* Optimize discount strategies and develop customer retention initiatives.

Visualizations

The project includes three visualizations:

1. Monthly Revenue Trend
2. Revenue by Product Category
3. Order Status Distribution

Project Outcome

This project demonstrates practical skills in data validation, preprocessing, KPI calculation, exploratory data analysis, visualization, and business insight generation using Python.
